# Icon Library

Reusable device and item icons for the Sentinel project.

These SVGs are intentionally standalone and unimplemented for now. Each icon uses:

- `viewBox="0 0 24 24"`
- `fill="none"`
- `stroke="currentColor"`
- rounded line caps and joins

That means the app can size and color them with CSS when they are wired in later.

## Suggested Use

```html
<img src="icons/light-switch.svg" alt="Light switch">
```

For inline styling, copy the SVG into markup or load it as a mask/background and set color in CSS.
