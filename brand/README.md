# Sentinel Brand Assets

Local logo and app-icon assets for Sentinel.

## Files

- `sentinel-app-icon.svg` - square app icon source.
- `sentinel-logo.svg` - horizontal logo with mark and wordmark.
- `sentinel-logo-light.svg` - horizontal logo for dark backgrounds.
- `sentinel-mark.svg` - standalone mark for small UI placements.

The SVGs are project-native vector assets and can be resized without quality loss.
